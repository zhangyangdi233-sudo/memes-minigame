# 60% 污染闪回分镜

## 戏剧目的

这不是“主角发疯”的展示。它是第二层语言秩序失效的第一个不可逆证据：玩家听见同一句关怀先后被玩偶和医生占用，却无法确认哪一次是记忆、预演或修改后的历史。

全长目标为 1.85 秒。整局只触发一次。触发时剩余行动归零，但日结必须等动画完整结束。

| 0.18-0.42 | 米白儿童椅和空出的玩偶位置出现，画面左侧缺一条窄帧 | `玩偶` 标签先出现 | 很近的布料摩擦；左声道一句呼吸前音 | 建立可在真结局回认的空位 motif |

## 视觉实现

- 使用固定场景数组，不再随机决定文字、位置或顺序。
- 图像只使用 Palette 1、Pollution Palette 5、米白和纯黑。
- glitch 只承担三种含义：横向撕裂代表阈值跨越；缺帧代表检索失败；重复偏移代表说话者归属冲突。
- 关键句永远完整可认。其余文字可使用局部裁切，但不堆满随机词。
- 闪回节点保存明确名称和 phase metadata，测试可以验证顺序、持续时间与关键文本。

## 声音实现

- 新音轨由原创合成层构成：布料噪声、短门扣、电话带宽语音占位、低频房间声和有意静音。
- 不使用尖叫、突然爆音、心跳或随机倒放人声。
- 峰值低于现有 UI 点击声约 3 dB，避免把心理变化变成惊吓音量测试。
- 玩偶与医生的声源距离感不同，但音高不做“邪恶化”处理。

## 真结局回收

隐藏第四层再次出现相同空椅和缺边方框。空白说话者第三次说：

`我只是想让你留在安全的地方。`

此时不揭示“真正说话者”。回收的答案是：句子已经变成一条能自行寻找说话者的语言规则，而不是玩偶或医生的私有记忆。

## 可访问性

- 不使用超过 3 次/秒的全屏明暗闪烁。
- 该限制遵循 [WCAG 2.2 闪烁阈值说明](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html)。
- 设置中保留视觉噪点开关；关闭后仍通过构图、文字、静音和缺帧表达同一信息。
- 动画不可跳过是因为它承担日结边界，但总时长低于 2 秒；退出游戏在动画结束后仍可立即使用。
