# 对话语气与逐场改写规范

## 共同规则

- 多数中文台词控制在 24 个可见字符内，紧张时更短。
- 每轮先出现具体动作或物件，再让人物绕开真正想问的事。
- 选择分别表达靠近、核对和拒绝，不再只是三种同义修辞。
- 一轮只引入一个异常。角色不会替玩家总结世界观。
- 停顿、改口、没回答和提前离开都可以构成有效反应。
- 玩偶和医生的关键语义污染由作者预写，禁止随机替词。

## 玩偶语言

**词汇**：我们、回家、乖、记住、名字、朋友、房间、不要丢下、一直、陪着。

**句长**：6 到 16 字。要求越强烈，句子越像温柔指令。

**语气**：亲密、具体、把共同记忆当作无需证明的事实。

**习惯**：给物品起私人的名字；把“我”改成“我们”；先替主角回答，再问主角是否同意。

**隐藏动机**：只要主角继续使用两人共享的称呼，这个世界就不会结束。

**回避**：不说“症状”“治疗”“醒来”。被追问时改谈房间、旧物或主角小时候的习惯。

**共享句**：必须先说 `我只是想让你留在安全的地方。`

**后段借用**：必须在医生说过后原样说 `你不需要再听见那个声音。`

## 医生语言

**词汇**：症状、记录、恢复、修正、重复、对象、表达、稳定、停止、分类、正常。

**句长**：10 到 22 字。压力上升时缩成检查项和动词。

**语气**：克制、程序化、像主角在心里复述曾听过的建议。

**习惯**：把情绪改写成观察；先要求主角描述事实；在主角沉默时补出一个“合理答案”。

**隐藏动机**：只要一切可以被分类，主角就不会再被无法解释的体验伤害。

**回避**：不承认自己也需要主角相信；不回答“你现在在哪里”。

**共享句**：必须先说 `你不需要再听见那个声音。`

**后段借用**：必须在玩偶说过后原样说 `我只是想让你留在安全的地方。`

## 主角

**词汇**：先、刚才、这里、我听见、我不确定、等一下。

**句长**：第一层完整，第二层出现改口，第三层常剩名词、代词和停顿。

**语气**：努力把事情说清楚，不主动发表哲学结论。

**习惯**：先核对物体位置，再核对说话者；借来的句子会比自己的句子更流畅。

**隐藏动机**：想保留一个不由玩偶或医生提供的第一人称。

**回避**：不轻易承诺“永远”“正常”“安全”。

## 现有普通 NPC

### 迟到者，NPC 索引 0

- 只谈时间、班次、票和迟到的后果。
- 句子短，常先给结论再小声修正。
- 想让主角陪等，但不直接承认害怕独自留下。
- 避免解释塔和污染；异常通过票面和报站出现。

### 回声住户，NPC 索引 1

- 使用门、水、管道、钥匙、楼上楼下等家务词。
- 重复主角最后一个名词，但会换掉一个方位。
- 想确认家里仍有人，却害怕听见准确回答。
- 不谈抽象“存在”，只问今晚能否关灯、门后是谁。

### 抄写员，NPC 索引 2

- 使用表格、行、空格、日期、签名。
- 礼貌而急，常在句中自己划掉一个词。
- 想让记录承担责任，避免承认自己改过内容。
- 不解释制度，只展示一处对不上的具体字段。

### 无名信徒，NPC 索引 3

- 使用站位、轮到、一起、唱完、不要插话。
- 说“大家”多于“我”，独处时会突然改回第一人称。
- 想被群体遮住，同时害怕自己的声音被认出。
- 不宣布信仰真理，只维护现场秩序。

### 旧帖目击者，NPC 索引 4

- 使用发帖时间、附件、回复、删除、缓存。
- 说话像转述屏幕，偶尔漏出一句私人请求。
- 想证明自己没有编造，又不敢给主角看完整内容。
- 不把论坛当档案或真相来源。

## 地图玩偶

玩偶不是商店角色，也不介绍价格。

- 每只玩偶先用一句极普通的摆放描述确认地点，例如“你把我放反了”。
- 它们都自称“我”，却对上一次见面给出微小不一致。
- 梗框是玩偶允许主角“替一个词留位置”的结果，不叫奖励或商品。
- 分支只改变获得的梗框、隐藏对话钥匙或一句以后会回来的称呼。
- 进度门槛通过它是否回答和现场摆放表现，不出现“尚未解锁”。

## 逐场改写地图

前三层地图中实际生成的普通 NPC 数量保持 `4/3/2`；对话目录条目数量保持 `5/4/3`；每个现有 archetype 仍由一段开场和两段 follow-up 构成三轮。首轮使用 `REALITY_DIALOGUES_BY_FLOOR`，后两轮使用 `REALITY_FOLLOWUPS_BY_NPC_INDEX`。这三项分别测试，不能用其中一项代替另外两项。

| 场景 | 原问题 | 新叙事功能 |
| --- | --- | --- |
| F1 迟到者 | 看不见的车是完整比喻，人物没有实际需求 | 用一张日期错误的票建立陪伴请求 |
| F1 回声住户 | 水管喊名字直接宣布异常 | 从关水、借扳手和不愿说门牌逐步泄露害怕 |
| F1 抄写员 | “纸学习删人”替作者讲主题 | 让第四行已被擦过，人物否认自己动笔 |
| F1 无名信徒 | 收据云意象与行动脱节 | 用站位和排队规则表现群体语言 |
| F1 旧帖目击者 | 十年前帖子过早给出大谜团 | 从无法删除的一句普通回复开始 |
| F2 同组人物 | 每句都直接解释遗产规则 | 让旧句妨碍眼前的道歉、问路、登记和点名 |
| F3 同组人物 | 官僚隐喻过密且节奏一致 | 让完整句逐渐变短，人物先处理具体缺词再暴露身份混淆 |
| 玩偶线 | 旧商人把梗框变成商品 | 通过命名、拒绝醒来和选择留下哪个词获得梗框 |
| 医生线 | 目前不存在稳定人物声音 | 通过主角内化的纠正语句介入现有节点，不增加外部 NPC |

每个改写节点都保留现有稳定 choice ID，避免破坏本地化和存档；只有文本、作者污染版本、语气标记和隐藏标记发生变化。
